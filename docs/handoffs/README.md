# handoffs/ — 作業ごとの進捗記録（過去の記録）

Issue・PRごとの途中経過・実測・残件・次の一手を残した記録。**時点のスナップショットで、現状の正本ではない**（現状はコード・GitHub・本番・[docs/](../README.md)の各文書）。古くなった記述を、現在の事実として扱わない。

- 最新の状況と次の一手: [LATEST](LATEST.md)
- 新しい引き継ぎの書き方: [TEMPLATE](TEMPLATE.md)（対象SHA・実行結果・残件・次の一手。事実と推測、成功と未実施を分ける）
- ファイル名の番号は、対応するIssue（`<番号>-progress.md`）。`P0-complete.md`・`P1-progress.md`は各Phaseの総括。`163-review.md`は運用前の独立レビューの結果。

## 主なファイル

| ファイル | 内容 |
|---|---|
| `2026-11-20-harness.md`・`2026-11-20-team-wsl.md` | 開発ハーネス（チェック・CI・Claude Team運用・WSL）の準備 |
| `P0-complete.md` | P0（基盤）の完了報告と受け入れ証拠 |
| `2`〜`125`のprogress | P0〜P4の各作業（認証・プロフィール・物品・通知・CMS・メディア・公式サイト・運用基盤） |
| `136`〜`157-progress.md` | ぬる P1〜P5（骨組み・Discord・Claude・予算・応答・自発・記憶・Web検索・日誌・リマインダー） |
| `163-review.md` | ぬるの運用前の独立レビュー（指摘と対応） |
| `165-progress.md`・`LATEST.md` | 運用開始に向けた確認・ドキュメント整理 |
